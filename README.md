# Kifula Premium

Plataforma premium para geração de trabalhos escolares em Angola.

## Funcionalidades

- Biblioteca inteligente de temas
- Pesquisa por escola, disciplina, província e tipo
- Gerador de trabalhos com resumo e conclusão
- PDF completo com validação por QR
- Planos premium e sistema de créditos
- Pronto para Vercel

## Como rodar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```
